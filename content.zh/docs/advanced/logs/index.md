入口：高级 → Xray。

## 本地日志

访问与错误日志分开查看，共用**一个记录开关**。日志策略中的“记录 DNS 查询”默认开启，但主日志开关关闭时不会因此开始记录。

- 访问日志：Xray 生成的连接访问记录。
- 错误日志：所选日志级别下的运行信息。

支持本地查看和可用平台上的导出，不提供暂停或删除操作。日志遵循 Xray-core 行为，不保证地址或凭据已脱敏。

**macOS OneXraySE 隐藏整个日志区域**，不提供原生文件日志读取。Mac App Store 与其他支持版本保留本地日志功能。

## 生成的配置

只读页面展示最近实际生成的 Xray 配置，不只是节点或 Raw 原文，可用于检查托管隧道、DNS、路由和出站。

可以查看或复制；修改应在智能／自定义设置或 Raw JSON 编辑器完成。不提供“复制诊断摘要”。

修改正在使用的日志／运行设置需要保存并重新连接。Raw JSON 不能替换 App 日志策略。

配置与日志可能含敏感地址或凭据，导出或提交 Issue 前请检查。
