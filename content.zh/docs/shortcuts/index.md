移动端快捷操作和桌面托盘分别设计，但连接、切换和更新行为与主界面保持一致。

## iOS 和 Android

长按 OneXray 应用图标，可以使用四个快捷操作：

| 操作 | 功能 |
| --- | --- |
| 启动 VPN | 使用已保存的配置连接；缺少设置或授权时仍需补齐。 |
| 停止 VPN | 停止当前连接。 |
| 切换配置 | 常规模式打开服务器页；专家模式打开连接页的 Raw JSON 选择界面。 |
| 更新订阅 | 按照已保存的设置更新订阅。 |

这里指应用图标的快捷操作，不是 Siri 快捷指令或系统自动化集成。

## 桌面托盘菜单

通过菜单栏或系统托盘中的图标，可以：

- 启动、停止或重新连接 VPN。
- 选择自动、订阅、位置或单个节点；专家模式下切换 Raw JSON 配置。
- 切换流量方式。
- 更新全部订阅或单个订阅。
- 更新路由数据，包括默认数据对或单个自定义数据源。
- 显示主窗口或退出 App。

每个动态数据列表最多显示十项。这只是菜单展示上限，不限制保存的数据数量，完整列表请在 App 中查看。自动选择、手动添加、更新全部等固定入口不占这十项；“更新全部”仍处理完整集合。

未连接时，切换只保存选择，不会自动启动 VPN。已连接时，影响当前连接的修改沿用 App 的确认与重连流程。更新结果和失败原因通过系统通知提示。没有服务器等托盘启动失败不会仅为展示错误而强制打开主窗口；需要交互的设置或授权可以打开窗口。

## 退出行为

macOS 和 Windows MSIX 的“退出”会保留 VPN 连接；如需同时停止，选择“退出并停止 VPN”。Windows EXE/ZIP 和 Linux 退出时会停止 VPN。
