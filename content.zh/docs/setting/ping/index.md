---
title: Ping
weight: 2
---

Ping 设置控制节点延迟测试，以及主页显示的连接探测。

| 字段 | 含义 |
| --- | --- |
| Timeout | 单次测试最大等待时间。 |
| Concurrency | 同时执行的节点测速任务上限。 |
| URL | 选择 Cloudflare 或 Google 测试地址。 |
| Resolved URL | 显示实际测试地址，点击后可复制。 |
| Auto Ping New Configs | 自动测试新导入的节点。 |

手动节点测速和自动测速会使用超时、并发数与所选测试地址。启动后主页的连接探测也会使用所选测试地址。
