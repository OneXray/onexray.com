设置页包含 App 级偏好、维护、版本信息和支持入口。

| 分区 | 内容 |
| --- | --- |
| 数据 | 自动更新、手动检查 App 更新、清除数据。 |
| App | 启动 App 后连接、桌面端启动行为、备份、iOS App 图标、主题和语言。 |
| 版本 | 已安装的 OneXray 与 Xray-core 版本。 |
| 支持 | 文档、评价、Telegram、Issue、源码、致谢和隐私。 |

OneXray 启动后会检查较新的稳定 GitHub Release，但不再自动弹出更新窗口。存在更新时，移动端 Settings 导航项会显示提醒；桌面端侧边栏底部会显示可点击提醒。只有用户主动操作时才打开支持 Markdown 的完整更新说明。

# 启动

“启动 App 后连接”适用于所有平台，默认关闭。开启后，OneXray 会在 App 服务准备完成后启动上次可用的配置；如果该配置已不存在，则随机选择一个节点。直连模式无需节点即可启动。

桌面平台还提供“桌面”二级页面：

| 设置 | 平台 | 行为 |
| --- | --- | --- |
| 登录时启动 | macOS、Windows、Linux | 使用操作系统的用户级启动机制注册 OneXray。 |
| 静默启动 | macOS、Windows、Linux | 每次启动 App 时保持主窗口隐藏，与“登录时启动”相互独立。 |
| 在程序坞中隐藏图标 | macOS | 隐藏 Dock 图标，并立即应用到当前 App 会话。 |

macOS 可能要求在“系统设置 > 通用 > 登录项”中批准。需要批准时，OneXray 会提供前往该页面的入口。

# 清除数据

清除数据会先停止 VPN，停止失败时取消清理。

成功后会删除配置、订阅、GeoData 数据库记录、运行时文件、缓存和自定义 GeoData，并恢复内置 `geosite` 与 `geoip`，当前 Xray 配置回到简易配置。

清理还会取消“登录时启动”，并重置“启动 App 后连接”和“静默启动”。本地备份 ZIP 以及隐私确认、First Run、简易配置、TUN 设置、主题、语言和平台外观偏好等其他设置会保留。
