设置页包含所有节点和配置共用的 App 级工具。

| 页面 | 用途 |
| --- | --- |
| TUN | 平台隧道选项、DNS 地址、网卡绑定、按需开启、按应用开启。 |
| Ping | 节点测试使用的 URL、超时和行为。 |
| 订阅更新 | 自动刷新订阅、自动测速和 GeoData 刷新。 |
| GeoData | `geosite:` 和 `geoip:` 规则使用的内置和自定义规则集。 |
| 日志 | App 日志、Xray 日志和生成的 Xray 配置文件。 |
| 备份 | 导出和恢复 OneXray 数据。 |
| 主题、语言、App 图标 | UI 偏好设置。 |
| 工具箱 | 辅助工具。 |

App 版本更新检查会在主页启动后执行。更新提醒会根据平台和 macOS System Extension 模式跳转到 App Store、Google Play 或 GitHub Releases。
