title: 启动与停止
weight: 5
---

使用 Home 底部的电源按钮启动或停止 VPN。

# 启动

OneXray 会依次：

1. 读取 Home 路由模式。
2. 加载当前 Xray 配置；无效时回退到简易配置。
3. 加载选中的 Outbound、Full Config 或 Raw Json；直连模式不要求节点。
4. 合成最终配置，并在需要时应用最终出口。
5. 应用规则、全局或直连模式转换。
6. 写入运行时 `tunIn`、当前 Xray 配置的额外入站和 `pingIn`，以及随机端口、metrics、GeoData 路径、网卡/路由字段和平台修正。
7. 写入运行时 `xray.json` 并启动平台 VPN/TUN。

# 切换路由模式

连接中切换规则、全局或直连属于重启操作。OneXray 会先停止当前 Core，再生成新的最终配置并重新启动。停止或启动失败时，Home 会显示失败状态，不会把新模式误报为已连接。

# 停止

停止会先结束当前 VPN/Core，再清理运行状态。Home 仍保留当前选中节点，供下一次规则或全局模式启动。

# 启动校验

| 情况 | 含义 |
| --- | --- |
| 缺少节点 | 规则或全局模式没有选中节点。 |
| Outbound 无效 | 节点无法转换为有效 Xray outbound。 |
| 最终出口缺失或无效 | 最终出口已删除，或不是有效 Outbound。 |
| 最终出口与当前节点相同 | 同一条本地 Outbound 同时承担两个角色。 |
| Raw Json 无效 | 保存内容无法归一化或生成运行时配置。 |
| 依赖缺失 | 全局模式找不到 `proxy` 或某个 `dialerProxy` 依赖。 |
