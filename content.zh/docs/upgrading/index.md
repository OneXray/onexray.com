## 从 26.9.1 升级至 26.9.2

26.9.2 在 26.9.1 重构后的界面上继续完善功能：

- 智能路由和自定义路由支持设置直连流量使用的[本地 DNS 地址]({{< relref "/docs/connect/smart-routing" >}})，并开放[隧道 DNS 的三项配置]({{< relref "/docs/advanced/vpn-tunnel" >}})。
- 订阅可按需发送随机生成、保持不变的 [HWID]({{< relref "/docs/servers/subscriptions" >}})，默认关闭，不读取硬件标识。
- 移动端提供四个应用图标快捷操作，桌面端扩展[托盘菜单]({{< relref "/docs/shortcuts" >}})。
- Apple 平台关闭“接管全部流量”后，可以配置[排除的网段]({{< relref "/docs/advanced/apple" >}})。
- 简化首次设置，进入主界面时完成必要的平台授权；连接失败时展示更具体的原因。
- Geodata 自动更新仅在 VPN 已连接时执行。更新失败保留旧文件，不断开或重启 VPN。
- Windows 安装包附带对应架构的 Microsoft Visual C++ 运行库；改进桌面 Core 生命周期、VPN 状态同步、窗口行为、系统分享和流量刷新。

数据库会原位升级，保留节点、订阅、Raw JSON、自定义路由、偏好设置和测速结果。新增的 HWID 开关默认关闭；未修改的路由继续使用默认本地 DNS。正常从 26.9.1 升级不需要卸载重装，也不需要重新完成首次设置。

[比较 v26.9.1 与 v26.9.2](https://github.com/OneXray/OneXray/compare/v26.9.1...v26.9.2)

## 从 v26.8.4 及更早版本升级

以下变化仅针对旧产品模型，不适用于 26.9.1 到 26.9.2 的更新。26.9.1 用四个主页面和独立的服务器／路由选择，替代了旧版配置流程。

### 更新前

请独立保存需要重新配置的内容。新版本不支持导入旧备份 ZIP。尤其是 Windows 用户，应先确认当前安装渠道。

### 保留的数据

数据库升级会保留本地节点、订阅与 Raw JSON。旧库中超过三份的 Raw 配置仍会完整显示、正常选择和编辑，只隐藏新增入口。

旧 Profile 与 Full Config 不再参与新界面和连接流程，也不会自动转换成自定义路由。需要的规则请在“自定义路由”重建，或整理为兼容的完整 Raw JSON。

从旧产品模型升级时会重置运行偏好。连接前重新检查服务器选择、路由、授权和平台 VPN 设置；节点延迟信息也会重新检测。

### 功能迁移

| 旧操作 | 新操作 |
| --- | --- |
| Home 节点列表和独立订阅页 | 服务器：按订阅或节点位置分组 |
| 简易配置、独立 Xray Profile | 智能路由与统一的高级设置 |
| 结构化 Full Config | 四类条件使用自定义路由，完整配置使用 Raw JSON |
| 规则／全局／直连 | 智能路由／所有流量经过 VPN／自定义路由 |
| 配置内的日志和隧道设置 | 高级 → VPN 隧道／Xray |
| 备份与恢复 | 已移除，保留独立配置的分享 |
| 历史累计流量 | 已移除，仅显示本次连接流量和速率 |

旧的独立“直连”模式不再是流量方式选项；直连仍是智能路由和自定义规则中的一种动作。

## Windows 渠道

EXE/ZIP 使用原生 TUN 和 UAC，MSIX 使用 Windows 系统 VPN。两者的数据目录、登录启动和退出行为不同。安装另一渠道不会自动导入原渠道数据。
