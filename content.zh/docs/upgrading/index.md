OneXray 26.9.1 用四个主页面和独立的服务器／路由选择，替代旧版配置流程。

## 更新前

请独立保存需要重新配置的内容。新版本不支持导入旧备份 ZIP。尤其是 Windows 用户，应先确认当前安装渠道。

## 保留的数据

数据库升级会保留本地节点、订阅与 Raw JSON。旧库中超过三份的 Raw 配置仍会完整显示、正常选择和编辑，只隐藏新增入口。

旧 Profile 与 Full Config 不再参与新界面和连接流程，也不会自动转换成自定义路由。需要的规则请在“自定义路由”重建，或整理为兼容的完整 Raw JSON。

从旧产品模型升级时会重置运行偏好。连接前重新检查服务器选择、路由、授权和平台 VPN 设置；节点延迟信息也会重新检测。

## 功能迁移

| 旧操作 | 新操作 |
| --- | --- |
| Home 节点列表和独立订阅页 | 服务器：按订阅或节点位置分组 |
| 简易配置、独立 Xray Profile | 智能路由与统一的高级设置 |
| 结构化 Full Config | 四类条件使用自定义路由，完整配置使用 Raw JSON |
| 规则／全局／直连 | 智能路由／所有流量经过 VPN／自定义路由 |
| 配置内的日志和隧道设置 | 高级 → VPN 隧道／Xray |
| 备份与恢复 | 已移除，保留独立配置的分享 |
| 历史累计流量 | 已移除，仅显示本次连接流量和速率 |

旧的独立“直连”模式不再是流量方式选项；直连仍是智能路由和自定义规则中的一种动作。

## Windows 渠道

EXE/ZIP 使用原生 TUN 和 UAC，MSIX 使用 Windows 系统 VPN。两者的数据目录、登录启动和退出行为不同。安装另一渠道不会自动导入原渠道数据。
