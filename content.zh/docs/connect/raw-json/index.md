在连接页开启专家模式。Raw JSON 区域替换普通服务器选择，通过添加或编辑进入 JSON 编辑器。

## 独立的完整配置流程

新安装默认没有 Raw 配置，最多新增三份。旧数据库中超过三份的配置仍完整显示、可选择和编辑，只隐藏添加入口。

为每份配置填写名称。完整 JSON 和 OneXray 链接都可用于导入和分享。需要从当前运行配置开始时，可在“高级 → Xray → 生成的配置”查看并复制。

普通服务器导入只提取节点，不会创建完整 Raw 配置。

## OneXray 接管的部分

| 区域 | 运行时行为 |
| --- | --- |
| 隧道 | 按平台生成 tunIn |
| 日志 | 以 App 日志策略和文件路径为准 |
| 流量 | 使用 App 管理的 metrics 和统计配置 |
| DNS 查询 | 根据 IPv6 偏好设置查询策略 |
| 文件 | 使用 App 管理的路由数据和证书路径 |
| Windows / Linux | 应用明确选择的 Xray 出口网卡 |

其他用户字段和额外入站会保留，但必须满足平台及保留资源约束。端口冲突或额外 TUN 不保证可运行。保存的原文与运行副本分开处理。

关闭 IPv6 只调整托管隧道参数和 DNS 查询，不额外添加 IPv6 阻断规则，也不保证所有用户自定义 IPv6 路径都被关闭。

## 校验与安全

校验由 libXray 构建配置完成；通过校验不代表 VPN 一定可以启动，也不代表远端服务器可达。

Raw JSON 不使用普通模式的智能／自定义规则。连接前确认配置与外部服务，分享前检查服务器凭据和订阅令牌。
