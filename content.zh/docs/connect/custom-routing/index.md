新建时选择**常规配置**或**高级 JSON**，两者共用三份上限，但编辑器与导入类型独立。高级 JSON 复用已有编辑器的导入、分享、保存和删除，并提供文档入口。自主 DNS、嗅探及额外本地入站见[高级模板规范]({{< relref "/docs/configuration/advanced-routing" >}})。下面的规则表单说明仅适用于常规配置。

打开连接 → 流量方式 → 自定义路由，新建或导入。实际节点仍在连接页选择。

## 编辑与应用

使用唯一名称，设置自动/分组选择的 1–3 个接入节点，最多保存三份。固定单个节点时仍使用该节点。

新增/编辑规则后，在固定底部按钮栏保存整份路由；规则子页只修改草稿。删除操作位于规则行内，没有启用/停用开关。有效改动影响当前路由时需要重连。

推荐每条规则只填一种条件；多种条件为“且”，同一普通列表内为候选项。域名/IP 输入支持基于已安装 Geodata 的自动补全。

## 生成与导入 JSON

[自定义路由规范]({{< relref "/docs/configuration/custom-routing" >}})统一说明字段、空槽、固定动作、本地 DNS 和完整下载示例。导入/分享走完整配置流程，不是普通服务器导入。

文件不放真实节点或 direct/block 出站，不支持字段直接拒绝。除了域名、IP、端口、网络，编辑器的“更多匹配条件”支持协议和操作系统；每份路由均有独立的 FakeDNS 开关，默认关闭。详见[版本与兼容性]({{< relref "/docs/configuration/compatibility" >}})。

本地 DNS 独立于隧道 DNS，只有纯域名直连规则贡献 DNS 域名，详见 [DNS 说明]({{< relref "/docs/configuration/dns" >}})。自定义 Geodata 需要真实文件、分类，不能有文件名冲突。
