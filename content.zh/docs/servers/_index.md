“服务器”包含“按订阅”和“按节点位置”两个 Tab，订阅在前并默认选中；两种分组共用节点列表页。

## 分组

订阅按 ID 排列。有本地节点时，“手动添加”固定在最前；没有时隐藏。

位置来源于各节点检测到的出口地区，不是节点名称，也不是当前设备的位置。新节点可能要等测速结束后才显示位置。

使用分组时，按当前路由要求选择对应数量的可用接入节点；使用单个节点则固定该节点。正在运行的节点会高亮。

## 节点行

展示名称、延迟状态，以及 VLESS | XHTTP | TLS 之类的协议标签。节点列表在导入和测速后自动更新，并按延迟排序。

| 标签 | 延迟 |
| --- | --- |
| 快 | 不超过 500 ms |
| 慢 | 大于 500 ms，不超过 1000 ms |
| 可用 | 大于 1000 ms |

未检测、失败与超时有独立状态。延迟只代表对测速地址的请求结果，不是带宽保证。

## 操作

节点与订阅均可编辑、分享和删除。节点使用 JSON 编辑器；订阅编辑复用添加时的名称、URL 和 age 设置。

订阅或位置批量测速支持取消，当前批次完成后停止。包括单节点在内的请求按顺序排队；测速不禁用节点的其他菜单。
