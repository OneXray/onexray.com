## 1. 完成系统准备

阅读隐私说明并同意继续。系统准备会建立本地配置和内置路由数据，并引导完成所需 VPN 授权。

Windows 和 Linux 还需要选择 Xray 出口网卡。“当前用于上网”的标记仅供参考，不会自动选择。Apple 设备在初始化时完成 VPN 授权；Android 可能还需要局域网权限。

初始化**不会启动 VPN**。每一步完成后手动点击“继续”，不会自动跳转。

## 2. 选择直连地区，可跳过

国家或地区用于智能路由的“直连地区”，不是选择 VPN 节点的位置。自动识别根据当前网络提供候选地区，不需要 GPS 权限；也可以手动单选、清空或跳过。

跳过保留已有设置，新安装默认使用中国大陆。若不需要直连地区，请清空选择、完成地区页面，再继续。之后可在[智能路由]({{< relref "/docs/connect/smart-routing" >}})修改。

## 3. 添加服务器，可跳过

可以添加订阅、粘贴分享链接、选择文件或输入节点 JSON。iOS 和 Android 还支持扫描二维码；文件导入直接打开系统选择器。

节点保存成功后，手动点击“进入首页”，无需等待测速或位置检测。也可以稍后添加；本地已有服务器时，这一步仍会展示。

## 4. 选择并连接

在“连接”页选择服务器来源和流量方式。可从“自动选择＋智能路由”开始；若只想测试一个节点，选择该节点和“所有流量经过 VPN”。

启动并等待“已连接”。页面可见时显示实时速率和本次连接流量；再次操作连接按钮即可停止。

## 遇到问题时

- 没有服务器：前往[服务器 → 添加服务器]({{< relref "/docs/servers/import" >}})。
- 缺少授权：使用连接页的授权入口，完成系统提示。
- 网卡已更换或不存在：前往“高级 → VPN 隧道”重新选择。
- 连接失败：检查配置来源、路由数据和[本地日志]({{< relref "/docs/advanced/logs" >}})。

正常启动仍会重新检查前置条件，不会因为曾经完成初始化就永久跳过权限和资源检查。
