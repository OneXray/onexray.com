Settings contains app-level tools that are shared by all nodes and configs.

| Page | Purpose |
| --- | --- |
| TUN | Platform tunnel options, DNS addresses, interface binding, on-demand rules, per-app VPN. |
| Ping | URL, timeout, and behavior used by node tests. |
| Subscription Update | Automatic subscription refresh, automatic ping, and GeoData refresh. |
| GeoData | Built-in and custom rule-set data used by `geosite:` and `geoip:` rules. |
| Log | App logs, Xray logs, and generated Xray config files. |
| Backup | Export and restore OneXray data. |
| Theme, Language, App Icon | UI preferences. |
| Toolbox | Utility actions. |

App update checks run from the Home page after the app has initialized. Update prompts link to App Store, Google Play, or GitHub Releases depending on platform and macOS System Extension mode.
