The Home page is the main operating surface. It contains node lists, Xray Setting entries, Raw Config entries, subscriptions, start and stop controls, search, import actions, and status feedback.

Configuration changes are applied the next time the VPN starts. If the VPN is already running, edit the configuration, stop the VPN, and start it again.

# Configuration Types

| Type | Purpose | Recommended for |
| --- | --- | --- |
| Outbound | A single Xray outbound node such as VLESS, VMess, Trojan, Shadowsocks, SOCKS, HTTP, or Hysteria2. | Most users and subscriptions. |
| Xray Setting | A structured reusable Xray configuration generated by OneXray UI pages. | Users who need custom DNS, routing, FakeDNS, chain proxy, logs, or extra outbounds. |
| Raw Config | A complete Xray JSON document imported and edited as text. | Advanced users who already understand Xray-core configuration. |
| Simple | A built-in Xray Setting writer controlled by the Simple Setting page. | Users who want working default routing and DNS. |

# Recommended Flow

1. Add an outbound node or subscription.
2. Keep the node's Xray Setting as `Simple`.
3. Adjust Simple Setting only when you need a different direct region, FakeDNS, chain proxy, DNS query strategy, or log level.
4. Start the VPN from the Home page.

# Status and Testing

When the VPN starts, OneXray writes an Xray config file into the app runtime directory and starts the platform network tunnel. After startup, the app can test latency and node IP information. Ping settings are shared by manual ping, subscription auto-ping, and post-start tests.
