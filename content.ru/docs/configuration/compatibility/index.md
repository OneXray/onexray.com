Проверено 2026-09-14. По умолчанию используйте выпущенный **26.9.2**, пока пользователь не подтвердит другую сборку. Пример для разработки не доказывает наличие функции в магазинах.

| Возможность | База 26.9.2 | Проверенная разработка |
| --- | --- | --- |
| Импорт outbound/Custom/Raw | Да | Да |
| Custom: домен, целевой IP, порт, сеть | Да | Да |
| Local DNS через app-dns-direct | Да | Да |
| Custom protocol/localOS | Нет | Да, нужна подтверждённая сборка |
| Smart/Custom FakeDNS, app-dns-fake | Нет | Да, нужна подтверждённая сборка |
| Автоматическое восстановление FakeDNS в управляемом Raw inbound | Руководство не обещает | Да в проверенной реализации FakeDNS |

При неизвестной версии используйте базовые поля или спросите. Не удаляйте условия незаметно для «совместимости». Raw не заменяет отсутствующую интеграцию платформы.

## Основания

- Выпущенное приложение: [v26.9.2](https://github.com/OneXray/OneXray/tree/v26.9.2), коммит `4bc391330f200c95fceff2aab64012ce98849c43`.
- Расширенные правила: коммит `92f34ad7ad2f11e0bb997aa3f92e0eed31336689`; FakeDNS проверен в последующей рабочей реализации, не объявленной здесь релизом.
- Проверка примеров: libXray `c145d94071088cebd445d7b0f4b1bea35732011e`, Xray-core `v1.260327.1-0.20260908222543-52a412d9e2f5`.
- [Манифест](/examples/manifest.json): тип, версия, зависимости и замены каждого файла.

Текущий upstream может быть новее встроенного Core. Структура импорта и управляемые поля определяются OneXray, допустимость протоколов — поставляемым libXray. Не смешивайте форматы других клиентов и старый VMessQrCode.

## Ограничения

До трёх Custom-профилей, уникальное имя длиной 1–32 символа, 1–3 пустых слота на профиль. Новых Raw — до трёх; старые записи сверх лимита сохраняются, кнопка добавления скрывается.

Обычному режиму нужны реальные узлы в приложении. Для автоматического/группового выбора требуется достаточно разных подходящих узлов; фиксированный одиночный выбор использует один сервер. Raw содержит свои узлы и не заимствует выбор обычного режима.

Домены примеров и UUID вымышлены. Замените их реквизитами поставщика; это не бесплатные рабочие серверы.
