Настройки Ping управляют проверкой задержки узлов и проверкой подключения,
которая отображается на Home.

| Поле | Значение |
| --- | --- |
| Timeout | Максимальное ожидание одного теста. |
| Concurrency | Максимальное число одновременных тестов узлов. |
| URL | Выбор тестового адреса Cloudflare или Google. |
| Resolved URL | Фактический тестовый адрес; нажмите, чтобы скопировать его. |
| Auto Ping New Configs | Автоматически тестировать новые импортированные узлы. |

Ручные и автоматические тесты используют timeout, concurrency и выбранный
адрес. Проверка подключения после запуска также использует выбранный адрес.
