Ping settings управляют latency tests узлов и connection checks.

| Поле | Значение |
| --- | --- |
| URL | Test URL для ping и connection checks. |
| Timeout | Максимальное ожидание одного теста. |

Home page ping, subscription auto-ping и post-start checks используют эту общую конфигурацию.
