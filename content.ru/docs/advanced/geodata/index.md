Откройте Дополнительно → Xray → данные маршрутизации. GeoData предоставляет категории доменов и IP для правил и подсказок редактора.

## Стандартные данные

- geosite.dat — доменные категории [domain-list-community](https://github.com/v2fly/domain-list-community).
- geoip.dat — IP-категории [geoip](https://github.com/v2fly/geoip).

Кнопка обновления в заголовке раздела обновляет **оба файла вместе**. Отдельное обновление и удаление недоступны.

## Собственные источники

Укажите имя/имя файла, тип (домены или IP) и HTTPS URL. Файл используется в ссылках правил вида ext:other.dat:cn.

Можно открыть сведения, обновить или удалить источник. Локальный импорт файла отсутствует. Данные становятся доступны после загрузки и проверки.

Файлы находятся в одном плоском управляемом каталоге. Подкаталоги и совпадающие имена не поддерживаются. Не перемещайте файлы вручную во время работы приложения.

## Категории и правила

Подсказки доменов/IP и прямые регионы используют установленные категории. Одного названия страны недостаточно для существования записи GeoSite/GeoIP.

Удаление файла может сделать ссылающийся маршрут недействительным. Сначала исправьте или удалите эти ссылки.

Общая Custom/Raw-конфигурация может объявлять зависимости по имени и URL. При импорте конфликт имени отклоняется без перезаписи. [Формат обмена]({{< relref "/docs/sharing" >}}).

Обновления действуют при последующих запусках, не заменяя правила активного Core на ходу. [Расписание обновлений]({{< relref "/docs/advanced/data-updates" >}}).
