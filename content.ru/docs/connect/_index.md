Страница разделяет два выбора: **какие серверы использовать** и **какой трафик направлять через них**.

## Серверы

- Автоматически — из доступных узлов.
- По подписке — только из выбранного источника.
- По местоположению — из узлов с соответствующим определённым регионом выхода.
- Один сервер — строго выбранный узел.

Умная и собственная маршрутизация задают 1–3 входных узла. Для автоматического выбора и групп используются результаты задержки; фиксированный сервер и режим «Всё через VPN» используют один узел. Фоновые тесты и обновления не заменяют узлы работающего VPN незаметно.

## Способ обработки трафика

| Режим | Назначение |
| --- | --- |
| [Умная маршрутизация]({{< relref "/docs/connect/smart-routing" >}}) | Прямые регионы и сервисы, управляемые переключателями |
| Всё через VPN | Трафик, поступивший в туннель, идёт через выбранный сервер |
| [Собственная маршрутизация]({{< relref "/docs/connect/custom-routing" >}}) | Ваши упорядоченные правила доменов, IP, портов и сети |

Выбор открывается в диалоге, редактирование — на отдельной странице.

«Всё через VPN» использует только Google DNS через прокси, без второго прямого DNS. Платформенные исключения, например списки приложений Android, по-прежнему определяют, что попадает в туннель. Это не гарантия системного kill switch.

## Экспертный режим

[Raw JSON]({{< relref "/docs/connect/raw-json" >}}) заменяет обычный выбор серверов. Его конфигурация не смешивается с обычными правилами. Прежний выбор сохраняется для возврата.

## Трафик и переподключение

Скорости и счётчики относятся к **текущему подключению**, а не к историческому итогу. Опрос идёт, пока страница подключения видна, в том числе когда окно компьютера теряет фокус. Скрытие окна или переход на другую страницу останавливает опрос. У блока трафика нет дополнительного окна.

У многосерверного подключения нет единственного IP, который представлял бы все выходы. Местоположение узла — результат его отдельного теста.

Изменения работающего подключения требуют переподключения. Сначала останавливается старый VPN, затем готовится и запускается новая конфигурация. Запуск использует локальные файлы маршрутизации: недостающие файлы не скачиваются, ожидания обновления geodata нет. При ошибке показывается причина; старое соединение автоматически не восстанавливается.
