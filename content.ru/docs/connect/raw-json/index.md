Включите экспертный режим на Подключении. Raw JSON заменит обычный выбор соединения; Add/Edit открывает JSON-редактор. Импортируйте как полную конфигурацию, не как серверы.

## Редактирование

Укажите имя. Новая установка не содержит Raw; можно добавить до трёх. Старые записи сверх лимита доступны, добавление скрыто. Перед обменом проверьте секреты и зависимости.

Raw не объединяется со Smart/Custom и не заимствует текущие серверы. Сохранение проверяет отдельную копию, не превращает исходник в runtime dump. Эффективные изменения активного профиля требуют переподключения.

## Правильный файл

[Контракт Raw]({{< relref "/docs/configuration/raw-json" >}}) содержит полные шаблоны, владение полями, DNS и цепочки. Управляемые туннель, журналы, метрики, стратегия запросов и интерфейс Windows/Linux не переопределяются JSON.

Успешное сохранение не доказывает доступность сервера или права запуска. Отсутствующий DAT — ошибка, не фоновое скачивание при старте VPN. См. [проверку]({{< relref "/docs/troubleshooting" >}}) и [зависимости]({{< relref "/docs/configuration/geodata" >}}).
