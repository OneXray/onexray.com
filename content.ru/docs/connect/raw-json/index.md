Включите экспертный режим на странице подключения. Raw JSON заменяет обычный выбор серверов; добавление и редактирование открывают JSON-редактор.

## Отдельный процесс

При новой установке Raw-конфигураций нет. Можно добавить до трёх. Если старых записей больше, все остаются видимыми и доступными для выбора и редактирования, но добавление скрывается.

Задайте имя конфигурации. Импорт и обмен поддерживают полный JSON и ссылки OneXray. Можно начать с копии фактической конфигурации из раздела Дополнительно → Xray.

Обычный импорт серверов извлекает только узлы и не создаёт полную Raw-конфигурацию.

## Что задаёт OneXray

| Область | Во время запуска |
| --- | --- |
| Туннель | Платформенный tunIn |
| Журналы | Политика и пути приложения |
| Трафик | Управляемые metrics и статистика |
| DNS-запросы | Стратегия согласно настройке IPv6 |
| Файлы | Каталоги данных маршрутизации и сертификатов |
| Windows / Linux | Выбранный исходящий интерфейс Xray |

Прочие поля и дополнительные входы сохраняются, если совместимы с платформой и зарезервированными ресурсами. Конфликтующий порт или дополнительный TUN не гарантированно работает. Сохранённый исходник отделён от рабочей копии.

Отключение IPv6 меняет управляемые параметры туннеля и DNS. Оно не добавляет блокирующие правила и не обещает отключить все пользовательские IPv6-пути.

## Проверка и безопасность

libXray проверяет построение конфигурации. Успех не доказывает, что VPN запустится или удалённый сервер доступен.

Raw JSON не использует обычные умные или собственные правила. Проверьте конфигурацию и внешние сервисы перед подключением. При обмене можно раскрыть учётные данные и токены.
