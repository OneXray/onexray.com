## 1. Подготовьте систему

Прочитайте уведомление о конфиденциальности и согласитесь продолжить. Системная подготовка создаёт локальную конфигурацию и встроенные данные маршрутизации, затем запрашивает необходимые разрешения VPN.

На Windows/Linux явно выберите исходящий интерфейс Xray. Отметка текущего интернет-интерфейса служит подсказкой, а не автоматическим выбором. На Apple разрешение VPN оформляется при первоначальной настройке; на Android может потребоваться доступ к локальной сети.

Настройка **не запускает VPN**. После каждого этапа нажимайте «Продолжить»: автоматического перехода нет.

## 2. Выберите прямой регион — необязательно

Регион определяет прямые правила умной маршрутизации, а не местоположение VPN-сервера. Определение по текущей сети предлагает вариант без GPS-разрешения. Можно выбрать один регион вручную, очистить выбор или пропустить шаг.

Пропуск сохраняет прежнюю настройку; при новой установке по умолчанию выбран материковый Китай. Если прямой регион не нужен, очистите выбор, завершите выбор региона и продолжите. Позже это можно изменить в [умной маршрутизации]({{< relref "/docs/connect/smart-routing" >}}).

## 3. Добавьте серверы — необязательно

Добавьте подписку, вставьте ссылку, выберите файл или введите JSON узла. На iOS/Android доступно сканирование QR-кодов. Импорт файла сразу открывает системное окно выбора.

Когда узлы сохранены, вручную перейдите на главный экран. Ждать проверки задержки и местоположения не нужно. Можно добавить серверы позже; шаг показывается и при наличии ранее добавленных узлов.

## 4. Выберите маршрут и подключитесь

На странице подключения выберите источник серверов и способ обработки трафика. Начать можно с автоматического выбора и умной маршрутизации. Для проверки одного сервера выберите его и режим «Всё через VPN».

Запустите VPN и дождитесь состояния подключения. На открытой странице отображаются текущие скорости и трафик сеанса. Здесь же можно отключиться.

## Если что-то не готово

- Нет серверов: [добавьте их]({{< relref "/docs/servers/import" >}}).
- Нет разрешения: используйте действие авторизации на странице подключения.
- Интерфейс пропал или изменился: выберите его снова в дополнительных настройках туннеля.
- Ошибка соединения: проверьте конфигурацию, данные маршрутизации и [локальные журналы]({{< relref "/docs/advanced/logs" >}}).

При обычном запуске необходимые условия проверяются снова. Завершённая настройка не заменяет проверку текущих разрешений.
