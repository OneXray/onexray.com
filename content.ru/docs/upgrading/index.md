OneXray 26.9.1 заменяет прежнюю работу с профилями четырьмя основными страницами и раздельным выбором серверов и правил.

## До обновления

Сохраните отдельно конфигурации, которые могут потребовать ручного переноса. Новая версия не импортирует старые ZIP-архивы резервных копий. На Windows проверьте канал установки.

## Сохранённые данные

Обновление базы сохраняет локальные узлы, подписки и Raw JSON. Если старых Raw-конфигураций больше трёх, все они остаются видимыми, доступными для выбора и редактирования; добавление скрывается.

Прежние Profile и Full Config больше не участвуют в интерфейсе и подключении. Они не преобразуются автоматически в собственные маршруты. Воссоздайте нужные правила в редакторе маршрутизации или подготовьте совместимый полный Raw JSON.

При переходе со старой модели сбрасываются рабочие настройки подключения. Перед запуском проверьте серверы, правила, разрешения и параметры платформенного VPN. Задержки узлов будут измерены заново.

## Куда переместились функции

| Раньше | Теперь |
| --- | --- |
| Узлы на Home и отдельные подписки | Серверы с группами по подписке или местоположению |
| Simple Profile и отдельные Xray Profiles | Умная маршрутизация и общие дополнительные настройки |
| Структурированный Full Config | Собственная маршрутизация для четырёх условий; Raw JSON для полной конфигурации |
| Rule / Global / Direct | Умная маршрутизация / Всё через VPN / Собственная маршрутизация |
| Журналы и туннель в профиле | Дополнительно → VPN Tunnel / Xray |
| Резервное копирование и восстановление | Удалено; обмен отдельными конфигурациями сохранён |
| Исторические суммарные счётчики | Только трафик и скорость текущего подключения |

Отдельного режима Direct больше нет. Прямое подключение остаётся действием внутри умных и собственных правил.

## Каналы Windows

EXE/ZIP использует нативный TUN с UAC, MSIX — системный VPN. Каталоги данных, автозапуск и выход различаются. Установка другого канала не переносит данные.
