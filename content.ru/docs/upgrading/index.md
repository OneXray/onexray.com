## С 26.9.1 на 26.9.2

Версия 26.9.2 развивает интерфейс, представленный в 26.9.1:

- Настройте [адрес локального DNS]({{< relref "/docs/connect/smart-routing" >}}) для прямого трафика в умной или собственной маршрутизации и три параметра [DNS туннеля]({{< relref "/docs/advanced/vpn-tunnel" >}}).
- При необходимости включите стабильный случайный [HWID подписки]({{< relref "/docs/servers/subscriptions" >}}). По умолчанию он отключён и не содержит идентификаторов оборудования.
- Используйте четыре действия значка приложения на телефоне и расширенное [меню трея на компьютере]({{< relref "/docs/shortcuts" >}}).
- Задайте [исключённые сети Apple]({{< relref "/docs/advanced/apple" >}}), когда захват всего трафика отключён.
- Пройдите сокращённую первоначальную настройку; системные разрешения запрашиваются при входе в основной интерфейс. Ошибки подключения показывают более конкретные причины.
- Автообновление geodata выполняется только при подключённом VPN. При ошибке остаются прежние файлы; VPN не отключается и не перезапускается.
- Пакеты Windows включают Microsoft Visual C++ Runtime нужной архитектуры. Улучшены жизненный цикл Core, состояние VPN, работа окон, системный обмен и обновление счётчиков трафика.

База обновляется на месте с сохранением узлов, подписок, Raw JSON, собственных маршрутов, настроек и результатов измерения задержки. Новые переключатели HWID отключены. Если адрес локального DNS не менять, маршруты сохраняют значение по умолчанию. Обычное обновление с 26.9.1 не требует переустановки или повторного прохождения Setup.

## С v26.8.4 и более ранних версий

Следующие изменения относятся к старой модели продукта, а не к переходу с 26.9.1 на 26.9.2. В 26.9.1 появились четыре основные страницы и раздельный выбор серверов и правил.

### До обновления

Сохраните отдельно конфигурации, которые могут потребовать ручного переноса. Новая версия не импортирует старые ZIP-архивы резервных копий. На Windows проверьте канал установки.

### Сохранённые данные

Обновление базы сохраняет локальные узлы, подписки и Raw JSON. Если старых Raw-конфигураций больше трёх, все они остаются видимыми, доступными для выбора и редактирования; добавление скрывается.

Прежние Profile и Full Config больше не участвуют в интерфейсе и подключении. Они не преобразуются автоматически в собственные маршруты. Воссоздайте нужные правила в редакторе маршрутизации или подготовьте совместимый полный Raw JSON.

При переходе со старой модели сбрасываются рабочие настройки подключения. Перед запуском проверьте серверы, правила, разрешения и параметры платформенного VPN. Задержки узлов будут измерены заново.

### Куда переместились функции

| Раньше | Теперь |
| --- | --- |
| Узлы на Home и отдельные подписки | Серверы с группами по подписке или местоположению |
| Simple Profile и отдельные Xray Profiles | Умная маршрутизация и общие дополнительные настройки |
| Структурированный Full Config | Собственная маршрутизация для четырёх условий; Raw JSON для полной конфигурации |
| Rule / Global / Direct | Умная маршрутизация / Всё через VPN / Собственная маршрутизация |
| Журналы и туннель в профиле | Дополнительно → VPN Tunnel / Xray |
| Резервное копирование и восстановление | Удалено; обмен отдельными конфигурациями сохранён |
| Исторические суммарные счётчики | Только трафик и скорость текущего подключения |

Отдельного режима Direct больше нет. Прямое подключение остаётся действием внутри умных и собственных правил.

## Каналы Windows

EXE/ZIP использует нативный TUN с UAC, MSIX — системный VPN. Каталоги данных, автозапуск и выход различаются. Установка другого канала не переносит данные.
