Откройте Серверы → Добавить серверы или выберите способ импорта во время первоначальной настройки.

| Способ | Действие |
| --- | --- |
| Буфер обмена | Показывает вставленный текст для отправки |
| Подписка | Имя, HTTPS URL, необязательные параметры age |
| Файл | Сразу открывает системный выбор файла |
| Вручную | JSON-редактор вместо форм отдельных протоколов |
| QR-код | Сканер только на iOS/Android |

Поддерживаются совместимые ссылки протоколов и узлы Xray JSON. Текстовые файлы и изображения QR-кодов можно выбрать через импорт файла.

## Что импортируется

Обычный импорт извлекает только outbounds. Маршрутизация, DNS и прочие корневые настройки не применяются. Для них используйте [собственную маршрутизацию]({{< relref "/docs/connect/custom-routing" >}}) или [Raw JSON]({{< relref "/docs/connect/raw-json" >}}).

Несколько подписок — по одному HTTPS URL на строку:

```text
https://example.com/sub-one#Personal
https://example.com/sub-two#Work
```

Фрагмент задаёт исходное имя и удаляется из сохранённого URL запроса. Это примеры формата, а не действующие подписки.

## Результат

После отправки текста, выбора файла или сканирования узлы сразу разбираются и сохраняются, без второго окна предпросмотра. Показывается число импортированных узлов. Если подходящих узлов нет, данные не записываются и выводится ошибка.

Новые узлы попадают в очередь тестов. Ждать тестов для завершения импорта или перехода из настройки на главный экран не нужно. Полные Raw/Custom-конфигурации и зависимости GeoData сохраняют собственный этап подтверждения.

Корректность узлов определяет libXray. Поддержка формата узла не означает поддержку всех настроек полного файла другого клиента.
